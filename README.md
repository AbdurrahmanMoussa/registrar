# Registrar Web Application

## Objective  
A Blazor and .NET-based web application designed to streamline student course registration and record management. This app features a normalized database schema using Entity Framework Core to ensure data integrity and supports CRUD operations for efficient administration of student and course data. The project demonstrates secure backend logic, validation, and version-controlled development using Git with a structured branching strategy.

## Features  
- Admin interface to manage students, courses, and enrollments  
- Full CRUD (Create, Read, Update, Delete) functionality for all entities  
- Normalized database schema ensuring accurate student-course relationships  
- Validation and secure handling of registration data  
- Git version control with branching strategy to maintain clean development workflow  

## Technologies Used  
- Blazor (ASP.NET Core)  
- Entity Framework Core  
- .NET 9 
- MySQL  
- Git for version control
